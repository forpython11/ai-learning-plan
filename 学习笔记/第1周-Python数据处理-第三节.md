# 第三节：用 Matplotlib 画图

## 本节目标

- 选择适合比较类别和观察变化的图表；
- 给图表添加标题、坐标轴标签和刻度；
- 把图保存成 PNG 文件。

## 1. 安装与运行

在项目根目录安装 Matplotlib：

```powershell
# 在项目虚拟环境里安装 Matplotlib。
.\.venv\Scripts\python.exe -m pip install matplotlib
```

运行本节练习：

```powershell
# 使用同一个虚拟环境运行画图脚本。
.\.venv\Scripts\python.exe .\练习代码\第1周-Python数据处理\第三节_Matplotlib画图.py
```

## 2. 两种图回答两类问题

- **柱状图**：比较不同类别的消费总额。
- **折线图**：观察每天的消费金额如何变化。

`plt.subplots(1, 2)` 会创建一行两张图。每张图都有自己的坐标轴对象，可以分别设置标题、轴标签和数据。

## 3. 保存图表

```python
fig.tight_layout()  # 自动调整两张图的间距。
fig.savefig(output_path, dpi=160)  # 保存为清晰的 PNG 图片。
```

`dpi` 控制图片分辨率；运行脚本后，`消费分析图.png` 会保存在脚本所在的文件夹，打开这张图片就能查看图表。
