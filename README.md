# AI 学习计划

这是一个 12 周的 AI 入门到应用项目，目标是：

- 掌握 Python 和机器学习基础
- 理解神经网络与 Transformer
- 能调用大模型 API
- 能独立做一个 RAG 知识库应用

## 学习节奏

每周建议投入 6—8 小时：

- 3 小时学习概念
- 2 小时跟着示例写代码
- 1—3 小时完成本周小项目

## 文件说明

- `学习计划.md`：完整的 12 周路线
- `学习笔记/`：记录概念、问题和总结
- `练习代码/`：保存代码练习
- `项目成果/`：保存阶段项目
- `进度记录.md`：每周打卡和复盘

## 开始方式

1. 安装 Python 3.11 或更新版本。
2. 安装 VS Code 和 Git。
3. 打开 `学习计划.md`，从第 1 周开始。
4. 每完成一周，在 `进度记录.md` 中打卡。

## 学习原则

先做小项目，再补理论；遇到不懂的概念，记录在笔记里，周末统一复习。
