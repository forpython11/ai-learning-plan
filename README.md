# AI 学习计划

这是一个面向已有 Python 基础学习者的 12 周 AI 实践路线，目标是：

- 用 Python 工具处理数据并完成基础机器学习项目
- 理解神经网络、文本表示与 Transformer
- 调用大模型完成实际任务
- 构建能引用学习资料的 RAG 应用

## 学习节奏

每周建议投入 6—8 小时：

- 约 2 小时学习概念
- 2—3 小时跟着示例写代码
- 2—3 小时完成本周练习并复盘

Python 变量、条件、循环、函数等基础不再单独安排一周；遇到具体缺口时按需复习。

## 文件说明

- `学习计划.md`：完整的 12 周路线
- `学习笔记/`：记录概念、问题和总结
- `练习代码/`：保存代码练习
- `项目成果/`：保存阶段项目
- `进度记录.md`：每周打卡和复盘

## 开始方式

1. 安装 Python 3.11 或更新版本。
2. 安装 VS Code 和 Git。
3. 打开 `学习计划.md`，从第 1 周的数据处理开始。
4. 每完成一周，在 `进度记录.md` 中打卡。

## 学习原则

每周先做出可运行的结果，再补理论；遇到不懂的概念，记录在笔记里，复盘时优先解决影响项目的问题。
